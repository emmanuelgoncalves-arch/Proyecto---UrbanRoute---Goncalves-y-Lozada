# UrbanRoute

UrbanRoute es una aplicación en Java que modela una red de transporte urbano como un grafo ponderado, usando una tabla hash propia para indexar las estaciones. Permite cargar la red desde un archivo CSV, modificarla, visualizarla, detectar subredes aisladas, calcular la ruta de menor tiempo e identificar los hubs de transferencia.
