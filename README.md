# Proyecto---UrbanRoute---Goncalves-y-Lozada
Desarrollamos una herramienta de software para modelar una red de transporte urbano como un grafo ponderado, apoyándonos en una hash table para la gestión e indexación eficiente de la información de las estaciones y aplicamos algoritmos para identificar hubs de transferencia, calcular las rutas más rápidas y simular interrupciones en la red.
